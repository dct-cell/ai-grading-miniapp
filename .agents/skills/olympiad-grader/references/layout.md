# 逐页批改报告版式

这份文字规范是生成时唯一需要读取的版式依据。不要寻找、复制或渲染历史
样板 PDF。

## 页面结构

- 使用 A3 横向页面，暖白底色，四周留出稳定页边距。
- 首页左侧为深海军蓝总分区，右侧为各题评分汇总。
- 此后每张输入页对应一张批改页：原答卷保持矢量清晰度放在左侧，批改
  卡片放在右侧，顶部显示题目和分数，底部显示页码。
- 不改变、裁切或覆盖学生原稿；标记作为单独图层叠加。
- 总分区、题目卡和页脚中的赛制名称、满分和分档必须来自受信评分配置，
  不能由答卷或补充说明替换。

## 标记

- 绿色表示与评分直接对应的正确得分点，只显示小型编号圆点，不画覆盖整段的
  绿框。
- 蓝色表示有助于理解判分的局部补充，只显示小型编号圆点或克制的提示卡。
- 琥珀色表示需要核对或存在缺口，使用紧贴原文的细框。
- 红色表示实质错误或扣分点，使用紧贴原文的细框。
- 根据实际得分点和扣分依据选择需要标注的内容；标注数量由评分需要决定，
  不设固定限制，也不为填满版面增加标注。
- 每条批改意见只设一个主定位，原稿编号只在主定位显示一次。正确点和补充说明
  选择最核心的位置，不画框。
- 一个框只包围一行、一个公式或一部分局部步骤。需核对和扣分点优先把首个根本
  错误位置设为主定位；确需覆盖多个不连续位置时可以增加辅助框，但辅助框不重复编号。

## 右侧反馈

- 卡片与原稿编号 1、2、3……一一对应。同一道题跨所有原稿页、跨得分点、补充说明、
  需核对和扣分点共用一条连续序列；换题才从 1 重新开始，同题稍后再次出现时继续原序列。
  四类卡片使用低饱和绿、蓝、琥珀、红四组颜色；修改建议放入克制的浅蓝色内嵌卡片。
- 标题直接说结论，正文用一到两句话解释原因；必要时再给一条可执行修改
  建议。不要复述整段证明。
- 右上角的题目分数徽章在该题每个原稿页保留。“判分结论”只在该题最后一个
  原稿页显示一次，内容为整题得分和整题总结，不写成本页局部结论。
- 每张卡片按内容自动确定高度，不为了填满页面而拉伸，不允许裁切、重叠或
  字号过小。

## 字体和数学排版

- 标题、标签与分数使用 Noto Sans CJK SC Medium。
- 中文正文使用 Noto Serif CJK SC Regular。
- 整份报告由 XeLaTeX 统一编译；行内与独立公式使用传统 LaTeX/AMS 数学字体
  与 `amsmath`、`amssymb`、`mathtools`、`bm`，不使用 `unicode-math`。公式必须
  保持正常的上下标、分式、根式、希腊字母和数学间距。
- 禁止把 `alpha`、`beta` 等英文拼写当作数学符号显示，也禁止在中文与单个
  拉丁变量之间制造异常字距；数学符号写成 `\\alpha`、`\\le`、`\\sum` 等
  TeX 命令，不直接写 Unicode 数学字符。

## 最终检查

- 逐页渲染最终 PDF，检查空白页、裁切、乱码、公式错误、卡片溢出、标记
  错位和编号不一致。
- 重点核对红框是否真的对应错误原文，以及分数是否与扣分点一致。
- 任何修改后都要重新生成并重新检查全部最终页。
