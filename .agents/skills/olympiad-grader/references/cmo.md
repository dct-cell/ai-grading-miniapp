# CMO 评分标准

每题满分 21 分，只使用 `0, 3, 6, 9, 12, 15, 18, 21` 八个分档。判断层次与
IMO 证明题一致，再映射到对应的 3 分档：

- 21：正确完整，只省略公认的常规小步骤。
- 18：核心方法和结论正确，有一个容易补齐的局部缺口。
- 12–15：主要思路正确且有实质进展，但有重要缺口、遗漏情形或局部错误。
- 6–9：有相关观察或有效引理，但距离完整证明较远。
- 3：只有很有限但确实正确的相关进展。
- 0：没有有效进展，或主要论证建立在错误事实上。

不为正确的常规小步骤扣分，同一根本错误不重复扣分。每题的得分和满分必须
分别为 3 的倍数和 21。

没有官方评标或完整参考解答时，仍从题面明确义务建立题目专属节点并继续批改，不编造隐藏
答案。缺少核心节点、主要分类、关键构造验证或需要新想法时，只累计已经严格完成的 3 分
节点；核心逻辑和主要义务都已完成、问题仅能沿原路线局部修正时，才从 21 分按 3 分档减分。
正确答案、少量例子、接近最优的弱界、方法名称和错误结论后的机械计算本身不得分，除非它们
确实完成了题目专属节点；一条分支的根错误也不能抹去另一条独立且有效的成果。
