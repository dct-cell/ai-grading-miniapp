# CMO 评分标准

每题满分 21 分，只使用 `0, 3, 6, 9, 12, 15, 18, 21` 八个分档。判断层次与
IMO 证明题一致，再映射到对应的 3 分档：

- 21：正确完整，只省略公认的常规小步骤。
- 18：核心方法和结论正确，有一个容易补齐的局部缺口。
- 12–15：主要思路正确且有实质进展，但有重要缺口、遗漏情形或局部错误。
- 6–9：有相关观察或有效引理，但距离完整证明较远。
- 3：只有很有限但确实正确的相关进展。
- 0：没有有效进展，或主要论证建立在错误事实上。

不为正确的常规小步骤扣分，同一根本错误不重复扣分。每题的得分和满分必须
分别为 3 的倍数和 21。
