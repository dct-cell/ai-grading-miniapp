# IMO 评分标准

每题 0–7 分，只给整数分。关注论证是否正确、完整、可验证。

- 7：正确且完整；可省略竞赛中公认的常规小步骤。
- 6：核心方法和结论正确，只有一个容易补齐的局部缺口或轻微笔误。
- 4–5：有正确的主要思路和实质进展，但存在重要缺口、遗漏情形或局部错误。
- 2–3：有相关观察或有效引理，但还未形成接近完整的证明。
- 1：只有很有限但确实正确的相关进展。
- 0：没有有效进展，或主要论证建立在错误事实上。

不为正确的常规化简、显然对称情形或标准定理的直接应用扣分。同一
根本错误不重复扣分。模糊手写按上下文最合理的数学含义理解并在内部记录；
模糊本身不自动扣分，只有采用的解释实质影响分数时才在报告中简短说明。
